# ARNG Eligibility Advisor

A web-based eligibility screening tool for **Army National Guard (ARNG)** recruiters. This application guides recruiters through a step-by-step screening process to evaluate applicant eligibility based on current regulations, SMOMs, and policy documents.

**Built by Andres Quintero**

---

## Features

- **Step-by-Step Eligibility Screener** — Walk through applicant criteria including age, citizenship, education, ASVAB/AFQT scores, moral/legal history, medical concerns, drug testing, dependents, REAL ID compliance, and Live Scan status.
- **Instant Eligibility Determination** — Receive an immediate assessment (Eligible, Conditional, or Ineligible) with detailed findings, required waivers, recommended next steps, and applicable regulation references.
- **Reference Library** — Browse the key regulations, SMOMs, and policy documents used for eligibility determinations, filterable by category.
- **Dark Military-Themed UI** — Clean, professional interface designed for daily recruiter use.

## Tech Stack

- **React 18** — Component-based UI
- **Vite 5** — Fast build tool and dev server
- **Netlify** — Hosting and deployment

## Getting Started

### Prerequisites
- Node.js v18 or higher
- npm or yarn

### Installation
git clone https://github.com/aquintero1102-hash/ARNG-Adviser.git
cd ARNG-Adviser
npm install

### Development
npm run dev

### Build for Production
npm run build

## Disclaimer

This tool provides **preliminary guidance only** and does not replace official eligibility determinations. Always verify against current regulations, SMOMs, and consult your chain of command for final decisions.
